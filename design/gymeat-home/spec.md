# 健食 GYMEAT ·「今天」首页 设计 spec

## 是什么
饮食营养记录 App（React + Tailwind，Capacitor 打包安卓，海外用户为主，中文界面）。
这次只定首页「今天」的视觉方向，选定后再铺到全 App。

## 给谁、在什么场景
用户本人 → 朋友 → 将来上架。一天打开 5～10 次：饭前看「还能吃多少」，饭后拍照记一笔，晚上看任务完没完成。单手、几秒钟。

## 核心信息（按重要程度）
1. 还能吃多少：「还能吃 825 kcal」，全屏最大的字
2. 今天的每日任务 + 连续天数（游戏化）：蛋白质吃够 74.5/150g、喝够 8 杯水 5/8、三餐都记上 2/3、称体重 ✓；连续 12 天
3. 今天吃了什么：早餐 460（燕麦牛奶 320 + 水煮蛋 140）、午餐 620（鸡胸肉饭）、加餐 95（苹果）、晚餐待记（建议 ≤700，比如三文鱼）
4. 三大营养素：蛋白 74.5/150、碳水 144/200、脂肪 32.3/65

## 情感基调
苹果感但不克制、不空；有创意；圆润；每个按钮、选项、区块按下去都有明显的反馈；像游戏一样有点上瘾，但不幼稚。

## 必须保留（用户点名）
- 底部导航：今天 / 趋势 / 中间大「+」/ 食物库 / 我的
- 顶部大数字「还能吃 825 kcal」
- 每日任务 + 连续天数

## 已否决（不要再出现）
三同心环；营养成分表黑白风；普通深色运动风；平涂卡通碗；写实玻璃碗；代码手画的角色/食物。

## 输出格式（三版统一）
- 安卓手机，412 × 892 内容区（Pixel 8 框），单文件 HTML
- 每版一块展示板：首页 + 添加食物弹层 + 一个任务完成的瞬间，都能点

## 素材
`assets/img/`：oatmeal / eggs / chicken-rice / apple / salmon，来源见 `credits.md`。
正式版里这些位置是用户自己拍的照片（拍照识别时就有），所以真图过诚实性测试：去掉它信息有损（你吃了什么）。
